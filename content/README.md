# Свои уроки

Весь курс — это TOML-файлы в этом каталоге. Кода трогать не нужно: уроки
вшиваются в бинарь через `include_dir!` при сборке, а `build.rs` следит за
каталогом, поэтому правка TOML вызывает пересборку сама.

```
content/
  chapters.toml            — список глав и их порядок
  chapters/<chapter>/*.toml — уроки
```

Имена файлов и подкаталогов ни на что не влияют: загрузчик рекурсивно собирает
все `*.toml`, кроме `chapters.toml`, а привязку к главе задаёт поле `chapter`
внутри урока. Каталоги — только для людей.

## Глава

Новая глава — блок в `content/chapters.toml`:

```toml
[[chapter]]
id = "macros"          # идентификатор, на него ссылаются уроки
order = 9              # позиция на карте
coming_soon = false    # true — глава видна, но помечена «скоро» (можно опустить)
[chapter.text.ru]
title = "Макросы"
subtitle = "q, @ и повтор пачкой"
[chapter.text.en]
title = "Macros"
subtitle = "q, @ and batch repeats"
```

Порядок глав несёт смысл: главы открываются по мере прохождения предыдущих.

## Урок

Один файл — один урок. Скелет:

```toml
id = "macros/record"   # уникальный id, по соглашению "<глава>/<имя>"
chapter = "macros"     # должен совпадать с id главы из chapters.toml
order = 39             # порядок сквозной по всему курсу, не внутри главы

[text.ru]
title = "Запись макроса"
intro = """
Абзац-другой о том, зачем эта команда. Многострочная строка TOML.
"""
[text.en]
title = "Recording a macro"
intro = """
A paragraph on why this command exists.
"""

[[exercise]]
# ... см. ниже
```

`order` сравнивается по всему курсу разом (ничьи разрешаются по `id`), так что
номера у существующих уроков идут сквозняком 1…38. Вставляя урок в середину,
либо сдвигай соседей, либо оставляй зазоры.

## Упражнение

```toml
[[exercise]]
buffer = ["let x = compute(a, b);", "let y = compute(c, d);"]
cursor = [0, 16]                     # [строка, столбец], оба с нуля; по умолчанию [0, 0]
goal = ["let x = compute();", "let y = compute();"]
goal_cursor = [1, 16]                # необязательно: только если важна позиция курсора
solutions = ["di(j.", "di(jdi("]     # все допустимые последовательности клавиш
[exercise.text.ru]
task = "Очисти аргументы в обоих вызовах."
hint = "Одно удаление объекта, дальше j и точка."
[exercise.text.en]
task = "Clear the arguments in both calls."
hint = "One object delete, then j and the dot."
```

Правила полей:

- `buffer`, `goal`, `solutions`, `text.task` — обязательны. Урок без упражнений
  или упражнение без решений валят тесты.
- `goal` пишется всегда, даже в уроках про движение: там он просто совпадает с
  `buffer`, а проверка идёт по `goal_cursor`.
- `goal_cursor` опускается, если позиция курсора после правки не важна. Тогда
  засчитывается любой курсор.
- Порядок в `solutions` значим:
  - **первое** решение — то, чему учит урок; его показывает строгий режим;
  - **самое короткое** — эталон для звёзд (3★ — уложился в эталон, 2★ — до
    полутора эталонов, 1★ — дольше).
  Так что первое решение — дидактическое, а не обязательно кратчайшее.
- Дубликаты в `solutions` запрещены тестом.

### Нотация клавиш

`solutions` разбираются той же нотацией, что и ввод пользователя: обычные
символы как есть, специальные — в угловых скобках.

| Токен | Клавиша |
|---|---|
| `<Esc>` | Esc |
| `<CR>`, `<Enter>`, `<Return>` | Enter |
| `<BS>` | Backspace |
| `<Tab>` | Tab |
| `<Space>` | пробел |
| `<C-r>` | Ctrl+r |
| `<lt>`, `<gt>` | `<`, `>` |

Нераспознанный `<...>` берётся буквально, посимвольно. Решение, входящее в
режим вставки, обязано из него выйти: `cwnew<Esc>` — иначе тест падает с
«решение оставляет редактор в режиме Insert».

### Что понимает движок

Не всё из настоящего vim реализовано. Доступно:

- движения: `h j k l w W b B e E 0 ^ $ { } gg G <n>G f F t T ; , n N / ? *`;
- операторы: `d c y` + движение, удвоение (`dd`, `cc`, `yy`), `D C Y`;
- текстовые объекты: `iw aw iW aW`, `i" a"`, `i' a'`, объект backtick-строки,
  `i( a( i[ a[ i{ a{ i< a<` (`b` и `B` — синонимы `(` и `{`), `ip ap`;
- правки: `x X s S r p P u <C-r> J .`, счётчики перед всем этим;
- вставка: `i a I A o O`;
- визуальный режим: `v V`, внутри — `d x c s y`;
- регистры: префикс `"a` перед оператором или `p`.

Явно не поддержаны (движок сообщит «не поддержано»): `<C-v>`, макросы `q @`,
метки `m`, `'`, backtick, командная строка `:`, отступы `> < =`, `%`, `R`, `ge`,
объект тега `it/at`, скроллинг.

## Языки

Тексты живут секциями по языкам прямо рядом с механикой — так перевод не может
разъехаться с логикой. Сейчас курс требует `ru` и `en`: тест проверяет, что у
каждого урока есть `title`, а у каждого упражнения — `task` на обоих языках.
При показе недостающий язык подменяется на `en`, потом на `ru`.

Строки интерфейса (кнопки, подписи) — не здесь, а в `locales/*.yml`.

## Проверка

```sh
cargo test
```

`tests/content.rs` прогоняет каждое заявленное решение через движок и сверяет
результат с `goal` и `goal_cursor` — то есть каждый урок сам себе тест. Ошибка
в упражнении выглядит так:

```
motion/hjkl #2 «2j4l»: получилось ["a b c"], ожидалось ["a b c", "d e f"]
```

Проверяется также: глава урока существует, урок не пустой, решения не
дублируются, эталон — действительно кратчайший, тексты есть на обоих языках.
Разбор TOML строгий: опечатка в поле роняет загрузку с паникой и именем файла.
